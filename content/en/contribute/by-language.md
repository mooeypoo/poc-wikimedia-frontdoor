# Contribute by programming language

Choose a project to contribute to based on programming language.

## Python

### Pywikibot

Pywikibot is a Python library and collection of scripts that automate work on Wikimedia projects.

:::link-row
[Read more on mediawiki.org](https://www.mediawiki.org/wiki/Special:MyLanguage/Manual:Pywikibot)

[Contribute](https://www.mediawiki.org/wiki/Special:MyLanguage/Manual:Pywikibot/Development)

[Get the source code](https://gerrit.wikimedia.org/g/pywikibot/core)
:::

### Scribe-Data

Scribe-Data is a command-line interface for extracting and formatting language data from Wikidata.

:::link-row
[Contribute](https://github.com/scribe-org/Scribe-Data/blob/main/CONTRIBUTING.md)

[Get the source code](https://github.com/scribe-org/Scribe-Data)
:::

## JavaScript

### Codex

Codex is a toolkit for building user interfaces within the Wikimedia Design System using Vue.

:::link-row
[Read the docs](https://doc.wikimedia.org/codex/latest)

[Contribute](https://doc.wikimedia.org/codex/latest/contributing/overview.html)

[Get the source code](https://gerrit.wikimedia.org/g/design/codex/)
:::

### SignIt Firefox Extension

A web-browser extension that translates words into sign language videos, so you can learn sign language while reading online.

:::link-row
[Read the docs](https://meta.wikimedia.org/wiki/Lingua_Libre/SignIt)

[Contribute](https://github.com/lingua-libre/SignIt/blob/master/README.md)

[Get the source code](https://github.com/lingua-libre/SignIt)
:::

### VideoCutTool

A tool to edit videos on Wikimedia Commons, built with React JS and Node JS.

:::link-row
[Read the docs](https://commons.wikimedia.org/wiki/Special:MyLanguage/Commons:VideoCutTool)

[Contribute](https://wikitech.wikimedia.org/wiki/Nova_Resource:Videocuttool/Installation)

[Get the source code](https://gitlab.wikimedia.org/cloudvps-repos/videocuttool/VideoCutTool)
:::
