# Get started with Wikimedia developer tools

Tools and bots make it easier to edit and maintain Wikimedia projects. Each Wikimedia project is managed by a community of volunteer. Although overlap exists between projects, you should get to know the community and policies of your local wiki to learn about best practices for editing and maintenance tasks.

## Discover and share tools

Browse the catalog of tools on Toolhub, share your tools, and help maintain tool metadata.

:::navigation-card-grid
::navigation-card{url="https://toolhub.wikimedia.org/" title="Toolhub" description="Toolhub is a catalog of tools that make it easier to edit and maintain Wikimedia projects. Use Toolhub to discover new tools, connect with tool maintainers, and share lists of your favorite tools."}

## Get started

Learn about way to get started using Wikimedia developer tools.

### Use the API explorer

The API explorer lets you interact with Wikimedia APIs using only your browser. By default, explorer requests are anonymous, but you can create an API token to authenticate your requests and even edit pages using your Wikimedia account.

[**Try out the API explorer →**](/explorer)

### Write code on wiki

On-wiki scripts interact directly with editor workflows and allow you to create custom wiki features for yourself and your wiki community.

:::navigation-card-grid
::navigation-card{url="https://www.mediawiki.org/wiki/Special:MyLanguage/Gadget_kitchen" title="Add JavaScript or CSS to a wiki" description="Customize MediaWiki with client-side JavaScript and CSS. Share user scripts, and explore gadgets other people have created."}
::

::navigation-card{url="https://doc.wikimedia.org/mediawiki-core/master/js/" title="MediaWiki frontend API" description="Interact with MediaWiki from user scripts, gadgets, skins, and extensions."}
::

::navigation-card{url="https://doc.wikimedia.org/codex/latest" title="UI toolkit" description="Codex helps you build user interfaces within the Wikimedia Design System using Vue."}

### Run scripts and queries

Scripts and queries are powerful tools to automate editing and other tasks.

:::navigation-card-grid
::navigation-card{url="https://www.mediawiki.org/wiki/Special:MyLanguage/Manual:Pywikibot/PAWS" title="Write your first script" description="Learn how to edit wiki pages using Python and the Pywikibot framework. This tutorial helps you get started quickly using only your browser."}
::

::navigation-card{url="https://wikitech.wikimedia.org/wiki/PAWS" title="Run scripts in your browser"}
PAWS is a free, cloud-hosted playground for creating scripts and data visualizations related to Wikimedia projects. Log in with your Wikimedia account and create a notebook to get started.
::

::navigation-card{url="https://quarry.wmcloud.org/" title="Query wiki databases"}
Use Quarry to run and share SQL queries against anonymized versions of Wikimedia databases.
::
:::
