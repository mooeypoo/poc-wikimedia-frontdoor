Tools and bots make it easier to edit and maintain Wikimedia projects.

## APIs

Explore programming interfaces for building bots and tools.

::highlight
[**Try the API explorer**](/explorer)

The API explorer lets you interact with Wikimedia APIs using only your browser. By default, explorer requests are anonymous, but you can create an API token to authenticate your requests and even edit pages using your Wikimedia account.
::

## Hosting

Access cloud services for performing analytics, administering bots, running web services, and hosting tools that help Wikimedia projects.

:::navigation-card-grid
::navigation-card{url="https://wikitech.wikimedia.org/wiki/PAWS" title="Run scripts in your browser"}
PAWS is a free, cloud-hosted playground for creating scripts and data visualizations related to Wikimedia projects. Log in with your Wikimedia account and create a notebook to get started.
::

::navigation-card{url="https://wikitech.wikimedia.org/wiki/Help:Toolforge" title="Learn about cloud hosting for tools" description="Toolforge is a free hosting environment for running and managing tools. Developing a tool in Toolforge makes it easier to access Wikimedia content and data and to share your tool with others."}
::
:::
