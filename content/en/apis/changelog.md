# Changelog

Explore the latest changes to Wikimedia APIs.

## April 2026

### Changed

- **All APIs -** Begin Phase 2 enforcement of [API Rate Limiting](Wikimedia_APIs/Rate_limits). Identified requests are now also subject to rate limits. Bots running in Toolforge/Wikimedia Cloud Services or with the bot user right on any wiki should not be affected. More information is available on the [WE5.1 project page](MediaWiki_Product_Insights/Responsible_Reuse/WE5.1:_Developer_authentication_and_authorization). (Week of April 28)

### Added

- **Attribution API -** Launch Attribution API (beta). The beta period will last at least 3 months before promoting the API to a v1. For more information, see the [Attribution API project page](Attribution_API). Users may provide feedback and request feature enhancements on the project [discussion page](Talk:Attribution_API), or file bugs directly through the [MediaWiki Interfaces Phabricator board](phab:project/view/6931/). (April 20, [T419545](phab:T419545))
