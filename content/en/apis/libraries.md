# Client libraries

Find client libraries for Wikimedia APIs.

::highlight
**Generate client code**

Wikimedia API docs are based on OpenAPI descriptions that you can use to generate client code. To download an OpenAPI description, open the API in the explorer, and select Download OpenAPI Document. [Browse code generators.](https://tools.openapis.org/categories/code-generators.html)
::

## JavaScript

* [pageviews.js](https://github.com/tomayac/pageviews.js) (page views and devices)

## Python

* [mwviews](https://github.com/mediawiki-utilities/python-mwviews) (page views)
* [pageviewapi](https://github.com/Commonists/pageview-api) (page views)

## R

* [waxer](https://github.com/wikimedia/waxer) (page views, devices, edits, editors, and media files)
* [pageviews](https://github.com/ironholds/pageviews) (page views)

## Add a library

To add a library to this page, leave a comment on the [project page on mediawiki.org](https://www.mediawiki.org/wiki/Talk:Developer_Portal).
