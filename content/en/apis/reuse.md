# Using free content

Articles on Wikipedia and content on other Wikimedia projects are licensed under a variety of free licenses, including Creative Commons licenses and others. You're free to use, remix, and distribute Wikimedia content as long as you follow the licensing requirements.

## Finding licenses

Before you include a piece of free content in your app, check the license. In general, Wikimedia projects use free licenses, but there are exceptions. Being aware of the license helps you comply with any restrictions and avoid surprises.

To find the license for a specific page or media file, use an API that returns the license in the response, such as the Content API or Attribution API. [Browse the API catalog.](/apis/catalog)

## Providing attribution

Properly attributing Wikimedia content is essential to the continued health of the free knowledge ecosystem. The Wikimedia attribution framework provides guidelines for fairly crediting Wikimedia content wherever it is surfaced. [Read the attribution framework.](https://wikimedia-attribution.toolforge.org/)

## Indicating changes

If you make any changes to the content, it’s important to indicate this in the attribution. For modified content, make sure to state clearly that modifications have been made. Some licenses, like the Creative Commons ShareAlike licenses, require that you license your modifications under the same license or a compatible license. Always check the applicable license for requirements for handling modifications.

## Using Wikipedia and Wikimedia logos

You're free to use Wikipedia and other Wikimedia logos to provide visual attrbution, but there are limitations to how you can use these logos. [Read the trademark policy.](https://foundation.wikimedia.org/wiki/Special:MyLanguage/Policy:Wikimedia_Foundation_Trademark_Policy)
