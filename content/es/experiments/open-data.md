## Before you start

All of the data linked from this page is publicly available and openly licensed.

You do not need an account or an API key to read it, though Wikimedia asks that every client identify itself with a descriptive [User-Agent header](https://meta.wikimedia.org/wiki/Special:MyLanguage/User-Agent_policy).

- Identify your client with a descriptive User-Agent header.
- Check the license of each dataset before you redistribute it.
- Prefer bulk downloads over crawling when you need data at scale.

| Data source | Format | Best for |
| --- | --- | --- |
| Dumps | XML \| SQL | Bulk analysis of a project's full history |
| Streams | JSON | Reacting to changes as they happen |
