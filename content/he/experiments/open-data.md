## לפני שמתחילים

כל הנתונים שמקושרים מהדף הזה זמינים לציבור ומופצים ברישיון חופשי.

אין צורך בחשבון או במפתח API כדי לקרוא אותם, אבל ויקימדיה מבקשת שכל תוכנה תזהה את עצמה באמצעות כותרת [User-Agent](https://meta.wikimedia.org/wiki/Special:MyLanguage/User-Agent_policy) מתארת.

- יש לזהות את התוכנה שלכם באמצעות כותרת User-Agent מתארת.
- יש לבדוק את הרישיון של כל מאגר נתונים לפני הפצה חוזרת שלו.
- כשצריך נתונים בהיקף גדול, עדיף להשתמש בהורדות מרוכזות ולא בסריקה של האתר.

| מקור הנתונים | פורמט | שימוש מומלץ |
| --- | --- | --- |
| דאמפים | XML \| SQL | ניתוח מקיף של כל ההיסטוריה של מיזם |
| זרמים | JSON | תגובה לשינויים בזמן אמת |
